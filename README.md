# WebBunon — Portfolio Website

## GitHub Pages-এ চালু করুন
1. ZIP extract করুন। GitHub-এ একটি Public repository তৈরি করুন।
2. index.html, style.css, app.js, config.js, assets ফোল্ডার এবং .nojekyll repository-এর root-এ আপলোড করুন। ZIP সরাসরি আপলোড করবেন না।
3. Settings > Pages > Deploy from a branch > main > /(root) > Save।
4. ডেপ্লয় শেষ হলে পাওয়া লাইভ লিংক Facebook Page-এর Links-এ বসাতে পারবেন।

Build বা package install প্রয়োজন নেই। সরাসরি index.html খুলেও দেখা যাবে। Fonts Google Fonts থেকে আসে; ইন্টারনেট না থাকলে fallback font ব্যবহার হবে।
